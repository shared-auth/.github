# Support

For roadmap, cross-repository planning, and internal delivery status, use the [shared-auth Linear project](https://linear.app/denman/project/githubcomshared-auth-acbca07bb390).

For a reproducible bug or a scoped feature request, open an issue in the affected repository using the organization issue forms. Include the repository, version or commit, client/provider, tenant/test environment, expected behavior, actual behavior, reproduction steps, impact, and sanitized logs.

Do not post vulnerabilities, tokens, cookies, credentials, OTP data, recovery codes, biometric data, personal data, or production data in public support channels. Follow [`SECURITY.md`](SECURITY.md) for private reporting.
