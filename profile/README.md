# shared-auth

Shared Auth develops reusable authentication, authorization, session, OTP, biometric, identity-provider, and tenant-access components for applications across the wider portfolio.

## Planning and governance

- Canonical Linear project: https://linear.app/denman/project/githubcomshared-auth-acbca07bb390
- Organization defaults and policies: https://github.com/shared-auth/.github
- Agent-safety policy: https://github.com/shared-auth/.github/blob/main/AGENTS.md
- Contribution guide: https://github.com/shared-auth/.github/blob/main/CONTRIBUTING.md
- Security policy: https://github.com/shared-auth/.github/security/policy

Every repository should link substantial work to Linear, resolve conflicts semantically with full historical and cross-repository context, preserve identity and session state non-destructively, and maintain a root `AGENTS.md` that preserves the organization-wide destructive-operation blacklist.
